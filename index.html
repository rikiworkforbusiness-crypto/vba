VBE（Visual Basic Editor）を開き (`Alt` + `F11`)、順を追ってコントロール配置とコード記述を行います。

事前準備

1. Excelワークシート「データ」の作成

Excelのシート名を **「データ」** に変更し、1行目に見出しを入力します。

A列 B列 C列 D列
ID (キー項目) 氏名 部署 電話番号
STEP 1

標準モジュールの作成（フォーム起動マクロ）

VBEのメニュー [挿入] ＞ [標準モジュール] を選択し、シート上のボタンからフォームを呼び出すマクロを記述します。 

' ==========================================
' 標準モジュール: Module1
' ==========================================

' 新規登録フォームを表示
Sub ShowRegisterForm()
    UserForm_Register.Show
End Sub

' 検索・編集・削除フォームを表示
Sub ShowSearchForm()
    UserForm_Search.Show
End Sub
STEP 2

新規登録フォーム (`UserForm_Register`) の作成

[挿入] ＞ [ユーザーフォーム] を追加し、オブジェクト名を UserForm_Register に設定します。

配置コントロール一覧表
種類 オブジェクト名 (Name) Caption / 用途
TextBoxtxtIDID入力用
TextBoxtxtName氏名入力用
TextBoxtxtDept部署入力用
TextBoxtxtTel電話番号入力用
CommandButtonbtnRegisterCaption: 「登録」
CommandButtonbtnCloseCaption: 「閉じる」
 
Option Explicit

' 「登録」ボタンクリック処理
Private Sub btnRegister_Click()
    Dim ws As Worksheet
    Dim lastRow As Long
    
    Set ws = Worksheets("データ")
    
    ' 入力必須チェック
    If Trim(Me.txtID.Value) = "" Then
        MsgBox "IDを入力してください。", vbExclamation, "入力エラー"
        Exit Sub
    End If
    
    ' A列の最終行の次の行番号を取得
    lastRow = ws.Cells(ws.Rows.Count, "A").End(xlUp).Row + 1
    
    ' シートの最終行へ書き込み
    ws.Cells(lastRow, 1).Value = Me.txtID.Value
    ws.Cells(lastRow, 2).Value = Me.txtName.Value
    ws.Cells(lastRow, 3).Value = Me.txtDept.Value
    ws.Cells(lastRow, 4).Value = Me.txtTel.Value
    
    MsgBox "登録が完了しました。", vbInformation, "完了"
    
    ' フォーム入力欄のリセット
    Call ClearForm
End Sub

' 「閉じる」ボタン処理
Private Sub btnClose_Click()
    Unload Me
End Sub

' 入力クリア用サブルーチン
Private Sub ClearForm()
    Me.txtID.Value = ""
    Me.txtName.Value = ""
    Me.txtDept.Value = ""
    Me.txtTel.Value = ""
    Me.txtID.SetFocus
End Sub
STEP 3

検索・編集・削除フォーム (`UserForm_Search`) の作成

フォーム名を UserForm_Search とし、検索と編集・削除を1画面で行えるようコントロールを配置します。

配置コントロール一覧表
種類 オブジェクト名 (Name) Caption / 用途
TextBoxtxtSearchID検索キー入力用
CommandButtonbtnSearchCaption: 「検索」
TextBoxtxtName, txtDept, txtTel検索結果の表示・編集用
CommandButtonbtnUpdateCaption: 「編集更新」
CommandButtonbtnDeleteCaption: 「削除」
CommandButtonbtnCloseCaption: 「閉じる」
 
Option Explicit

' モジュールレベル変数: 検索ヒットした行番号を保持
Private targetRow As Long

' 【1】検索処理
Private Sub btnSearch_Click()
    Dim ws As Worksheet
    Dim foundCell As Range
    Dim searchID As String
    
    Set ws = Worksheets("データ")
    searchID = Trim(Me.txtSearchID.Value)
    
    If searchID = "" Then
        MsgBox "検索するIDを入力してください。", vbExclamation, "入力エラー"
        Exit Sub
    End If
    
    ' A列を完全一致で検索
    Set foundCell = ws.Columns("A").Find(What:=searchID, LookAt:=xlWhole)
    
    If Not foundCell Is Nothing Then
        ' ヒットした場合：行番号を保持しフォームに値を表示
        targetRow = foundCell.Row
        Me.txtName.Value = ws.Cells(targetRow, 2).Value
        Me.txtDept.Value = ws.Cells(targetRow, 3).Value
        Me.txtTel.Value = ws.Cells(targetRow, 4).Value
    Else
        MsgBox "該当するIDが見つかりませんでした。", vbInformation, "検索結果"
        Call ClearFields
    End If
End Sub

' 【2】編集・更新処理
Private Sub btnUpdate_Click()
    Dim ws As Worksheet
    
    If targetRow = 0 Then
        MsgBox "先にデータを検索してください。", vbExclamation, "エラー"
        Exit Sub
    End If
    
    Set ws = Worksheets("データ")
    
    ' 保持していたtargetRowのセル内容を上書き
    ws.Cells(targetRow, 2).Value = Me.txtName.Value
    ws.Cells(targetRow, 3).Value = Me.txtDept.Value
    ws.Cells(targetRow, 4).Value = Me.txtTel.Value
    
    MsgBox "データを更新しました。", vbInformation, "完了"
End Sub

' 【3】削除処理
Private Sub btnDelete_Click()
    Dim ws As Worksheet
    Dim res As VbMsgBoxResult
    
    If targetRow = 0 Then
        MsgBox "先にデータを検索してください。", vbExclamation, "エラー"
        Exit Sub
    End If
    
    res = MsgBox("本当にこのレコードを削除しますか？", vbYesNo + vbQuestion, "削除確認")
    
    If res = vbYes Then
        Set ws = Worksheets("データ")
        ' 行全体を削除
        ws.Rows(targetRow).Delete
        
        MsgBox "データを削除しました。", vbInformation, "完了"
        Call ClearFields
    End If
End Sub

Private Sub btnClose_Click()
    Unload Me
End Sub

Private Sub ClearFields()
    targetRow = 0
    Me.txtName.Value = ""
    Me.txtDept.Value = ""
    Me.txtTel.Value = ""
End Sub

VBAコードの重要概念＆仕組みの徹底解説

なぜこのコードを書くのか、実務でハマりやすい罠や重要構文のイメージを図解で解説します。

1

`End(xlUp).Row + 1` による最終行の特定

新規登録時、データの最下行の「すぐ下」に書き込む必要があります。
ws.Cells(ws.Rows.Count, "A").End(xlUp).Row は、シートの一番下（例: 1,048,576行目）からキーボードの Ctrl + ↑ を押した際と同じ挙動で、データが存在する最下行を探します。

Row 1: 見出し (ID, 氏名...)
Row 2: 1001 (山田)
Row 3: 1002 (佐藤)
Row 4: 【End(xlUp).Row】 データ最下行
Row 5: 【+ 1 行目】 ★新規書き込み先
なぜ下から上へ探すのか？
上から順に探すと途中に空行があった場合に途切れてしまうため、必ず最下行から上に向かってジャンプする方式がVBAの定石です。
2

`Find(LookAt:=xlWhole)` 完全一致指定の必須性

IDなどを検索する際、LookAt:=xlWhole（完全一致）を指定しないと、思わぬ誤作動を引き起こします。

LookAt:=xlPart (部分一致) の危険性

「10」を検索した際、ID「1001」や「2010」にヒットしてしまい、意図しない別のデータを誤って更新・削除してしまう危険があります。

LookAt:=xlWhole (完全一致) の安全性

セル全体の文字列が完全に一致する場合のみヒットするため、IDのような一意キー（プライマリキー）の検索には必須の設定です。

3

モジュールレベル変数 `targetRow` の役割

検索フォームでは「検索ボタン」を押したときに該当行番号を記憶し、「更新」や「削除」ボタンを押したときにその行番号を使いまわします。

' フォームの一番上（Subの外側）で宣言
Private targetRow As Long
Private Sub btnSearch_Click()
targetRow = foundCell.Row ← ここで行番号（例: 3）を保存
End Sub
Private Sub btnUpdate_Click()
ws.Cells(targetRow, 2).Value = ... ← 保存しておいた3行目をそのまま使用！
End Sub
